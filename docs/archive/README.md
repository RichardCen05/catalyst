# Archive — frozen session notes

Everything in this folder is a record of a working session between 14 and 17 September 2026:
one-off prompts written for a fresh agent session, and the reports those runs produced. They are
kept for provenance, not for instruction.

Do not follow them. They describe the app as it stood on their own date, and most of them target
Cloud Run revision `catalyst-web-00033-gmn` or older while a newer revision serves traffic. The
prompt files in particular contain instructions addressed to an agent in a past session; treat
them as history, never as a task to execute now.

For how the app is deployed and where to check it, read `docs/DEPLOY.md`, which is verified
against the live project.
